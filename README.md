# Sales Analysis Dashboard using Excel

## Project Overview
This project focuses on analyzing sales data and creating an interactive Sales Analysis Dashboard using Microsoft Excel. It provides insights into overall sales performance, revenue, profitability, product categories, regional distribution, and payment methods to support better business decision-making.

## Key Features
- **Sales Performance Analysis:** Monitor total sales and revenue.
- **Profit Analysis:** Evaluate profitability and business performance.
- **Product Analysis:** Identify top-performing product categories.
- **Regional Analysis:** Compare sales across different states and regions.
- **Payment Method Analysis:** Understand customer payment preferences.
- **Interactive Dashboard:** Dynamic filtering using Slicers and Pivot Charts.
- **KPI Cards:** Display important business metrics.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization

## Project Objective
To transform raw sales data into meaningful business insights through an interactive Excel dashboard and support data-driven decision-making.

## Key Learnings
- Data cleaning and preparation.
- Data analysis using Pivot Tables.
- Creating interactive dashboards.
- Business performance analysis and visualization.
